# Miras Preview for Joomla: releases

Update feed and installable packages of **Miras Preview** (`pkg_mirasarticleimages`), a Joomla 6 extension that makes every article present itself well in search engines and social networks from its own content:

- fills an empty intro image with the first suitable image of the article, on save or in reviewed batches;
- fills an empty meta description from the article text, or with an AI provider of your choice (Anthropic, OpenAI or OpenAI-compatible), always reviewed before it is written;
- writes Open Graph and X tags from those fields (optional plugin).

Every batch is simulated first, written article by article with a log, and can be rolled back. The source code is maintained privately; packages are released under the GNU General Public License version 2 or later.

- Packages: see Releases.
